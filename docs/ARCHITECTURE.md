# Архитектура Genesis Core v0.1

Headless-ядро, экспериментальная лаборатория и будущий viewer разделены.
Пакет устанавливается из `src/`, сторонний код не импортируется из текущего каталога.

| Модуль | Ответственность | Текущее состояние |
| --- | --- | --- |
| `genesis.config` | Frozen dataclasses, строгий YAML, схема v1 | реализован |
| `genesis.core` | Тики, RNG, состояние, топология, оркестрация | реализован |
| `genesis.environment` | Генерация полей и локальный перенос ресурса | реализован |
| `genesis.agents` | Временные агенты в SoA | только пространство имён |
| `genesis.evolution` | Наследование и мутации стенда | только пространство имён |
| `genesis.chemistry` | Универсальные взаимодействия | только пространство имён |
| `genesis.lab` | Наблюдение, далее batch runner и статистика | метрики среды |
| `genesis.history` | Метаданные и артефакты, далее checkpoint/replay | минимальная запись |
| `genesis.viewer` | Чтение истории и визуализация | только пространство имён |

`core.simulation` оркестрирует `environment`; численный модуль среды использует
контракты `core.state` и `core.topology`, а не `Simulation`. Циклических импортов нет.
Ядро не зависит от CLI, хранилища, viewer или временной агентной модели.

## Состояние и время

Индексация `[y,x]`, float64 C-contiguous поля: elevation, temperature, humidity,
light, resource; bool land. Условия статичны в `environment-v1` и доступны только
для чтения. Обновляется только resource и скалярный журнал потока. 1 тик = 1 условная
единица времени; размеры и ресурсы в условных единицах, температура — условные °C.
Проверки конечности/неотрицательности выполняются каждый тик.
Пустой мир допустим; генератор не добавляет сушу скрытой «починкой».

## Локальные правила ресурса

1. Синхронная диффузия: `D_i = R_i + d * sum(R_j - R_i)` по четырём соседям суши.
2. Явный внешний приток: `I_i = source_rate * light_i * humidity_i * land_i`.
3. Потери: `L_i = decay * (D_i + I_i)`, затем `R'_i = D_i + I_i - L_i`.

`0 <= d <= 0.25`, `0 <= decay <= 1`: неотрицательность и устойчивость stencil.
Нет обрезания ресурса по максимуму/минимуму и неучтённой регенерации.
Суммарно `R(t) = R(0) + source_total - sink_total`, с погрешностью float64.
Это открытый резервуар энергии: внешний приток и уход в неотслеживаемое тепло.
Масса вещества пока не моделируется. Поздняя chemistry обязана иметь собственный
баланс вещества и энергии; нельзя трактовать этот скаляр как готовую биохимию.

Closed: края и вода непроницаемы, отсутствующий сосед не участвует в обмене.
Periodic: противоположные края связаны. Для размеров 1 и 2 сохраняется кратность
четырёх направлений решётки; сосед-сам-себе даёт нулевой поток.
Горы и широта задают температуру; освещённость зависит от широты, влажность —
seeded поле. Температура ещё не влияет на ресурс; сезоны и климатическая динамика
не добавлены. Суша формируется максимумом гауссовых островов + небольшим шумом.
Это заданная география тестового стенда, не заявление об эмерджентности.

## RNG и воспроизводимость

`SeedSequence(seed).spawn(2)` → явные `Generator(PCG64)` для среды (индекс 0)
и будущих агентов (индекс 1). Глобальный NumPy RNG не используется. Порядок потоков
версионируется; новые потоки можно только дописывать в конец с пересмотром контракта.
После генерации текущая среда детерминирована и не потребляет RNG на каждом шаге.

Гарантия: тот же код, разрешённый конфиг, версии Python/NumPy, CPU-бэкенд и платформа
дают идентичные поля и digest. Между версиями зависимостей, архитектурами, CPU/GPU
и ОС идентичность не гарантируется: генерация включает `exp` и float64 reductions.
Digest включает поля, tick и ledger; это не digest checkpoint будущей агентной модели:
когда появится стохастическая динамика, надо включить состояния всех RNG (S01-6).

Конфигурационная, state и artifact схемы имеют независимые номера 1; правила —
`environment-v1`. Неизвестные конфигурационные схемы отклоняются; миграции сейчас
не нужны и не реализованы. NPZ — конечное наблюдение, загрузчик для resume не заявлен.

## Масштабирование

SoA для будущих агентов; наблюдатели читают метрики отдельно от закона отбора.
Сейчас NumPy, без Numba/GPU до профиля реального агентного цикла. Независимые миры
позже распределяются по процессам; shared RNG между мирами запрещён.
Граница 4194304 клеток защищает от случайного чрезмерного выделения памяти;
её повышение требует оценки буферов и памяти. GPU-идентичность — отдельный контракт.
