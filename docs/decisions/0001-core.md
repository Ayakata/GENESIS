# ADR-0001: переносимый CPU-стенд среды

Дата: 2026-10-18. Статус: принято для S01-1/S01-2.

1. Python >=3.11, NumPy float64 и PyYAML; pytest, Ruff и strict mypy для проверки.
   Реальная проверка в этой итерации — CPython 3.12 Linux x86_64.
   Пользовательский Windows-диск не смонтирован, поэтому приложение передаётся
   переносимым исходным проектом с отдельным venv и точной инструкцией запуска.
2. `src`-layout и один Python distribution `genesis-alife`; доменные модули разделены
   без преждевременного множества пакетов и сервисов. Никаких предзаданных видов.
3. Четыре соседних клетки, closed или periodic границы, синхронный stencil.
   Диффузия не переносит ресурс через воду; приток и потери имеют явный ledger.
4. Ресурс — энергетический суррогат открытой системы. Ранняя модель намеренно
   не заявляет сохранение массы. Её ограничение описано в архитектуре и метриках.
5. Замороженные dataclasses вместо нового validation framework; YAML отклоняет
   опечатки, дубликаты, bool вместо чисел, NaN/Inf, неизвестные схемы и неустойчивые
   параметры. Конфиг обязан явно содержать schema_version; остальные поля имеют defaults.
6. Минимальная запись YAML/JSONL/NPZ нужна для проверяемости этой итерации.
   Она не закрывает S01-5/S01-6: batch, resume, RNG checkpoint и события впереди.
7. Numba, Parquet и GUI отложены до появления агента и профиля. Добавление их сейчас
   усложнило бы установку и не проверило бы полезное ускорение.
8. История разработки хранится в локальном Git. Внешний remote не предоставлен;
   bundle в архиве позволяет восстановить коммиты без создания внешнего репозитория.
9. Проверка импульса `0.6113431084989805` при d=0.25 обнаружила отрицательный
   остаток `-5.55e-17` при последовательном вычитании потоков. Формула заменена
   эквивалентной выпуклой суммой весов центра/соседей. Значения не обрезаются:
   неотрицательность обеспечена вычислением, а баланс проверяется отдельно.
