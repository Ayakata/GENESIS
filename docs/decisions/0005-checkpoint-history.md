# ADR-0005: полные checkpoints и событийная история

Статус: принят для S01-6, 2026-10-18.

## Решение

Resumable checkpoint — отдельный версионированный контракт, а не расширение итогового
инспекционного NPZ. Он сохраняет все поля мира, активный SoA агентов, ресурсный,
агентный и эволюционный ledgers, `next_id`, исходный resolved config и состояния обоих
генераторов PCG64. Инициализация при загрузке не повторяется и RNG не потребляется.

Payload хранится в NPZ без pickle. Рядом находится JSON-sidecar с версиями, тиком,
digest научного состояния и SHA-256 всего файла. Запись payload и sidecar выполняется
через временные файлы и atomic replace; существующие checkpoints не перезаписываются.
Загрузчик до восстановления проверяет SHA-256, точный набор полей, dtype/shape,
config/state/checkpoint schemas, ruleset, ledgers, геометрию, диапазоны и итоговый digest.

`run.steps` при resume означает число **дополнительных** тиков. Разрешено менять только
run-control (`steps`, интервалы метрик/checkpoints); seed и законы мира остаются из
checkpoint. Manifest нового запуска хранит SHA-256, digest и абсолютный тик родителя.
Непрерывный запуск и цепочка run→resume обязаны совпадать по состоянию, RNG, метрикам
и последовательности tick-events.

Каждый артефакт содержит `events.jsonl`: `run_started`, один агрегированный `tick` на
шаг, `checkpoint`, терминальный `run_completed` либо `run_failed`. Tick-event включает
явные ресурсные/энергетические потоки, счётчики мутаций, ID рождённых и родителей,
ID умерших. Журнал является наблюдением и не влияет на симуляцию или fitness.

## Версии и ограничения

- config schema v4 добавляет `run.checkpoint_interval`; artifact schema v4 фиксирует
  events/checkpoints/lineage; checkpoint schema v1 и event schema v1 независимы.
- State schema остаётся v3, ruleset — `environment-v1+agents-v2+evolution-v1`:
  численные законы и представление научного состояния не менялись.
- Итоговый `final_state.npz` остаётся удобной инспекционной копией и не загружается
  для resume; источником восстановления служит только проверенный checkpoint.
- Формат поддерживает один локальный файл. Инкрементальные/распределённые snapshots,
  миграции старых схем и восстановление оборванной записи не входят в S01-6.
