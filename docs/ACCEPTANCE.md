# Приёмка S01-1 и S01-2

Условия проверяются до изменения чекбоксов в `GENESIS_ROADMAP.md`.

## S01-1

- Пакет устанавливается editable и из wheel; CLI доступен как `genesis` и `python -m genesis`.
- `init` создаёт полный YAML; `validate` читает его и печатает разрешённые значения.
- Неизвестные ключи/схемы, некорректные типы/диапазоны и дубликаты отклоняются.
- Одна документированная последовательность создаёт окружение, запускает тесты и опыт.
- Ruff lint/format и mypy strict проходят; wheel/sdist собираются.
- Тестовый CLI работает из отдельного процесса, ошибки дают код 2, результаты не затираются.

## S01-2

- 2D-поля генерируются из seed, имеют форму `[height,width]`; миры не делят массивы/RNG.
- Два отдельных процесса с одинаковым config дают одинаковые digest и метрики.
- Разные seeds изменяют мир; потребление agent-stream не изменяет stream среды.
- Closed/periodic края и непроницаемая вода проверены известным импульсом и барьером.
- Диффузия сохраняет сумму и неотрицательность, включая 1x1, 1xN, 2x2 и d=0.25.
- При отсутствии источника/потерь сумма сохраняется; decay=1 удаляет весь ресурс в ledger.
- Одноклеточная система совпадает с аналитическим решением рекуррентного уравнения.
- На 3 seeds, в двух краевых режимах и в закрытом контроле нет NaN/Inf/отрицательных полей;
  абсолютный остаток баланса <1e-8 в контрольном сценарии 96x64/200 тиков.
- Разрешённый конфиг, seed, версия правил/схем, fingerprint кода и зависимости сохранены.

## Команды

```bash
python -m pytest
python -m ruff check .
python -m ruff format --check .
python -m mypy
python -m build --no-isolation
python experiments/s01_environment/reproduce.py --output runs/acceptance
```

`experiments/s01_environment/evidence/` и `docs/PROGRESS.md` содержат фактический
результат, версии и ссылку на проверенный implementation commit. Проверки не
подтверждают эволюцию, адаптацию или возникновение жизни — эти критерии впереди.
